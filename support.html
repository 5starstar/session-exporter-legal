Support

Write to charmszaku@gmail.com. It is a one-person project, so replies can take a few days.

What to include

  • The version shown in the popup’s header (for example v0.10.0) and your browser and its version.
  • Whether it was a Claude Code session or a chat, which goal and format you picked, and whether Fast mode was on.
  • What you expected, and what you saw (the exact words in the card or in the popup help).

Please do not send a real session or chat. They can contain private things, commands, paths and secrets. Describe what happened instead.

Common questions

Is this official?

No. It is an independent project, not made, endorsed or supported by Anthropic.

What does it send, and where?

Nothing to the maker and nothing to any third party. The only requests it can make go to claude.ai itself, to read your own session or chat. See the privacy policy.

The popup says “Open a Claude Code session or a chat first”

The extension only works on a Claude Code session (an address that starts with claude.ai/code/) or a chat (claude.ai/chat/). Open one, then click the extension’s icon again.

Why does Fast mode ask me to confirm?

Fast mode reads the session’s or chat’s own data directly instead of scrolling the page. It relies on an unofficial part of claude.ai that can change, and claude.ai’s terms may not allow automated access, so you decide, after reading the warning. It is off by default for Claude Code sessions. A chat can only be saved this way.

The file says it may be incomplete

The notice after an export says when the session was still running, when some parts could not be read, or when the history may be incomplete. Wait until the session has finished and export again. If it keeps happening, write with what you did and the exact notice.

Who is the character, and how do I turn it off?

It is the maker’s own creation, made with Google Flow (an AI image tool). It is not an official Anthropic or Claude mascot. To switch it off, open the popup, then More options, and untick Show the companion.

Does it work in Firefox or Safari?

Not yet.

How do I remove everything it keeps?

Uninstall the extension. It keeps only small settings in its own storage (see the privacy policy), and they go with it.
